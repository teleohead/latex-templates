# My LaTeX Templates

## Usage

* `give.cls` — for assignment submission.
* `take.cls` — for note taking.
* `craft.cls` — for report submission.
* `cheat.cls` — for exam cheatsheets.

## Tip
Set the following command on your computer so that your TeX compiler can locate these files automatically.
```
export TEXINPUTS="~/path/to/the/repo//:"
```
